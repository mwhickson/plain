# PLAIN Examples

This collection of examples is meant to offer an accumulated body of working PLAIN code.

These examples also serve as a testing ground to ensure PLAIN works as desired, and to hightlight areas where the underlying language can be improved or is outright missing features/functionality.

Some examples are standalone, others are geared toward highlighting module functionality.

NOTE: Module-oriented examples are not meant to be exhaustive. They should (typically) showcase common module functionality.
