# PLAIN Programming Language

PLAIN (Programming Language Allowing Implementation Neatly) is a BASIC-like/inspired-by-BASIC programming language.

PLAIN, and its associated tooling, is intended to fill software development niches historically attributed to dBase, Delphi, FoxPro, HyperCard, MS Access, PowerBuilder, Xojo, and Visual Basic.

> NOTE: PLAIN is a working-title backronym.

## Goals

PLAIN strives to meet the following goals:

- accessible to professionals, hobbyists and the general public alike
- easy to read, easy to write, easy to reason about/with
- structured, yet flexible
- "batteries included" for modern desktop application programming
- "fast enough"
- easy to share -- code and resulting executable programs
- cross-platform (Windows, Linux, MacOS)
- small

## Features

PLAIN endeavors to provide the following features in a modular fashion:

- strongly typed variables
- financial and computer science math functions
- robust, if minimal, cross-platform (native) GUI support
- networking via HTTTP client support
- data support for CSV, JSON, XML, and sqlite
- multimedia (images, audio, video)

## Non-targets

PLAIN will not actively prevent development in the following areas, but is not built with considerations for the following in mind:

- 3D graphics
- "big data" processing
- games
- mobile applications
- real-time applications
- high-performance, high-security server tasks
- web applications
